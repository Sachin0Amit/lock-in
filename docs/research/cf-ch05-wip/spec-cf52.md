## The arc (the LIBRARY lesson — the workers priced on the reader's own machine; NOT a product catalogue)
1. **The worker defined** (the mirror of 5.1's manager): *application
   software is said to be software that performs the user's own task,
   standing on the platform the system software keeps.* The test that
   sorts ANY program: 'whose job does it do — the machine's or yours?'
   Run the test on 4 named programs honestly (an OS = machine's; a
   word processor = yours; a driver = machine's; a browser = yours).
2. **The seven worker families** (THE census table + map figure):
   (i) productivity (word processor, spreadsheet, presentation, email
   client — the 4 core kinds); (ii) creative and media (photo, video,
   audio, desktop publishing); (iii) browsers and content access (the
   Web door — ch.6 doorstep, named not opened); (iv) communication
   (chat, video calls); (v) education and reference (encyclopedias,
   tutors — THIS library honestly names itself as one); (vi)
   developer tools (editors, IDEs, compilers — the ch.3 bit-craft's
   workbench door); (vii) games and simulation. ONE line each: the
   family's verb (compose, compute, narrate, reach, converse, learn,
   build, play).
3. **One family studied close: the spreadsheet** (so the census is not
   a list): the grid (26 columns A..Z × 100 rows = 2,600 cells), a
   formula as a RECIPE the machine re-cooks when ingredients change,
   one SUM over a 100-cell column = 99 additions. Storage honesty:
   2,600 cells at 8 bytes each = 20,800 bytes = 20.3125 KiB
   (engine-pinned). The word processor's cousin run (compose →
   format → print is a recipe too).
4. **Three uniforms, one worker** (desktop installable vs web app vs
   mobile app — the same worker in three uniforms; what changes:
   where it lives, who updates it, when it needs the network). Tie
   forward to 5.3 (installing/updating) without stealing its ground.
5. **Suites vs single-purpose** (honest economics): a 4-app suite at
   one licence vs 4 singles at 4 licences; when a suite's spare apps
   are dead weight and when they are the point.
6. **Choosing honestly** (the reader's own machine): file formats as
   contracts (cross-reference ch.3's text/formats ground), export
   before you commit, the lock-in question ('can your work leave?').
   A Caution callout: 'free' apps priced in attention/data — named
   honestly, one paragraph, no sermon.
7. **Two dated beats, honestly told (OUR OWN retelling)**: VisiCalc,
   1979 — the first spreadsheet (Apple II), the program that sold the
   machine: the 'killer app' idea born. Photoshop, 1990 (the Knoll
   brothers) — the creative family's household name; 11 years after
   VisiCalc. Name-drop only what the census needs.
8. **Doorsteps**: 'Computer Networks' (planned) owns the browser's
   plumbing; 'Programming ...' shelf books own the developer-tools
   craft; this lesson keeps the family census and the choosing
   instinct.
9. Exam corner: 'classify the given software', 'spreadsheet
   purpose', 'suites vs packages', 'examples per family',
   'web vs desktop app'.
