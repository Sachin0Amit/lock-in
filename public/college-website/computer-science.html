About

The Computer Science Department

CSC School of Computer Science
1,200+ open-source pull requests per year

The School of Computer Science runs a shipping-first curriculum: the first course ends with a deployed web service, the second with a version-controlled systems project, and by the final year every student has committed to an open-source repository or an internship codebase.

The school's private cloud sandbox mirrors a production stack — build pipelines, containers, monitoring — so electives in cloud, security and machine learning run on real infrastructure rather than slides. Its Demo Day is the university's largest recruiting window.

  • Ship-software-first course sequence
  • Private cloud sandbox mirroring production
  • Open-source contribution counts toward electives
  • GPU cluster open to all project students
